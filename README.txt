BENJAMIN RUTO CAMPAIGN WEBSITE

Files included:
- index.html
- manifesto.html
- gallery.html
- styles.css
- script.js
- assets/

How to use:
1. Extract the ZIP.
2. Open index.html in your browser.
3. To publish on GitHub Pages, upload all files and folders as they are.
4. To make the WhatsApp button work, replace https://wa.me/ in the HTML with your full WhatsApp link.

You can further customize:
- Candidate biography section
- Contact details
- Downloadable manifesto PDF
- More images and campaign updates
